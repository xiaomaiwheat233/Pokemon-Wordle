# 宝可梦弗一把 🎯

一个宝可梦版的「猜猜我是谁」小游戏（Pokémon Wordle）。系统随机抽取一只宝可梦，你在 8 次机会内通过种族值、属性、世代、特性等逐项对比反馈猜出它。

当前版本还支持好友房、手动 WebRTC 连接和 Toy 排位：好友房使用 `webConnect.js` 的房间信令；排位使用 B站 Toy JS SDK 的个人云存储与官方排行榜，胜负各调整 25 分，排位对局固定使用全图鉴题库。

## ✨ 玩法

- 选择参与世代（全部 / 第一至第九世代），点击「开始竞猜」
- 每次猜测后逐项给出反馈：<b>绿色</b> = 正确 · <b>黄色</b> = 接近 · <b>灰色</b> = 不对，数值附 <b>↑</b>（答案更高）/ <b>↓</b>（答案更低）
- 最后一次竞猜时给出目标剪影图
- 每局限用一次提示（三选一）：名字字数 / 名字第一个字 / 自动填入一只 ≥ 半数数据吻合的宝可梦（消耗一次竞猜）
- 可随时「🏳️ 放弃」直接公布答案
- 「👥 双人对战」支持房间码好友房和复制粘贴 SDP 的手动连接；「🏆 排位榜」支持 Toy 官方榜单、周期筛选和排位匹配

## 🚀 运行

纯静态页面，无需构建：直接用浏览器打开 `index.html` 即可。页面通过 CDN 加载 B站 Toy SDK 与 `webconnect@0.0.12`；发布到 Toy 时需要网络可用。

## 📦 Toy 打包

上传包应只包含运行所需的 `index.html`、`css/`、`js/` 和宝可梦图片，不要把 `.git`、原始 HTML 数据页或 `node_modules` 放进 ZIP。当前可上传包为 `pokemon-wordle-toy-upload-v10.zip`。
